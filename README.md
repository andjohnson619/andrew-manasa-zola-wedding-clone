# Andrew & Manasa Wedding Website

A static multi-page wedding website replicating the Zola "Jessenia" theme (pale sage).

## Pages

- **Home** (`index.html`): Hero photos, couple names, date, location, and live countdown
- **Schedule** (`schedule.html`): Full event timeline for Friday Oct 9 and Saturday Oct 10
- **Travel** (`travel.html`): Hotel block information (Rancho Bernardo Inn)
- **FAQs** (`faq.html`): Common guest questions about attire, logistics, kids, parking, etc.

## Theme

- Background: `#56643f` (pale sage green)
- Text/accent: `#f4e7c6` (warm cream)
- Header font: Cormorant Infant (Google Fonts)
- Body font: Libre Baskerville (Google Fonts)
